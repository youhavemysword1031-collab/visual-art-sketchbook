# Visual art & sketchbook — Nancy (Yanxi) Zhou

A responsive, buildless portfolio of 15 visual art and sketchbook studies from 2023–2026.

Live portfolio: https://youhavemysword1031-collab.github.io/visual-art-sketchbook/

Open `index.html` in a modern browser. The page uses local assets and system fonts with no external dependencies, analytics, or build process. GitHub Pages serves the root of `main`; `.nojekyll` keeps deployment static.

The gallery uses three columns on desktop, two at widths up to 1000 px, and one at widths up to 600 px. Select any work to open the full-screen viewer. Use the arrows or keyboard Arrow keys to browse, Escape to close, and Zoom to inspect. The tall sketchbook sheet includes four supplementary detail panels.

See [IMAGE_AUDIT.md](IMAGE_AUDIT.md) for the source-to-export mapping and dimensions. Originals remain outside version control. All web images use JPEG quality 85 and a maximum width or height of 1600 px.
